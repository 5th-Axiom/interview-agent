评估先给出一句面试结论和下一轮建议，再列 3～5 条关键依据（证据少可更少）。结论最多 80 字符，每条依据最多 60 字符；原文引用、设置与历史默认折叠。评估卡片 PC 固定 520px、H5 固定 480px，内容内部滚动，重新生成按钮固定在卡片底部。旧版本保留，重新生成后使用新格式；人工复核独立保存。

实现目标是可运行的 AI 语音面试产品，覆盖候选人与招聘方完整链路。详细功能以本目录 PRD 和技术方案为准；不以静态页面或模拟对话作为完整交付。

## 必须保持的产品行为

- 2026-09-15：面试记录可按「重面待审核 / 可再次面试」筛选，支持组合条件、分页、清空与返回保留。可再次面试仅显示开放入口下最新已结束正式场次中已批准且未使用的资格，列表显示相应标记；查询不修改资格。

- 2026-09-15：字幕开启后同时显示「AI 面试官 / 我」，候选人临时识别原地修订，AI 句子跟随实际播放开始展示。限定高度、内部滚动，支持翻阅时停止自动跟随与「回到最新」。打断、暂停与断线保留已展示文字并标明未确认状态；隐藏字幕不影响语音或保存。试聊与正式面试共用实现。

- 2026-09-15：岗位编辑增加「帮我写面试说明」，点击后以弹窗展示，表单与草稿内部滚动，不占用原有页面文档流。支持从简介提取能力建议、确认重点、选择面试方式、补充追问要求，并预览可编辑的 Prompt 草稿；确认填入后沿用原有保存、发布和试聊。关闭弹窗取消请求并保留本页输入与草稿。提取和生成复用实际配置的非实时模型，测试模式显式标识。工程不维护独立题单或阶段状态，辅助设置不作为运行时配置；失败、取消和过期响应不得覆盖当前说明。

- 候选人通过招聘链接登录，先授权麦克风并试音；点击或明确说出岗位后直接开始，无第二次岗位确认。
- 面试以圆球语音交互为中心，不显示阶段进度条，字幕默认隐藏。可以静音、暂停、继续、返回重新选岗、确认结束。
- 换岗保留整场历史并添加岗位片段；正式开始后一小时截止，暂停、断线和换岗均不延长。展示的有效时长另算。
- 断网停止收音和播放，重连后由候选人点击继续；再次进入恢复同一未结束会话，已到期则进入反馈页。
- 结束后反馈评分、问题、文字或语音说明，可跳过；可以申请再次面试。招聘方通过后才允许新一轮，一次资格仅消费一次。
- 招聘方管理岗位、编辑 Prompt、试聊与发布；查看记录、文字与录音、AI 评估，编辑本次评估 Prompt 并重新生成，独立保存人工复核，审核再次面试申请。
- 试聊不占正式候选人资格；反馈语音不进入面试上下文或评估。

## 技术实现重点

- 单场连续上下文：平台规则、当前岗位 Prompt、服务端事实、带来源的滚动摘要、最近原文和新发言。压缩原子更新、失败保留旧版本，评估取证依据原文。
- 双向打断：前端立即停声，后端取消模型与 TTS；回复编号和连接代次贯穿所有事件，旧结果不能改新状态。
- ASR 区分临时、最终、修订与连接就绪；处理中途停顿、长回答、中文夹英文、连续补充与供应商连接轮换。
- 模型输出逐句送 TTS，工具通道与可朗读内容分离；备用模型遵守相同上下文和工具契约。
- 文本固定批次发送，收到持久化回执再清理；录音逐片保存，回放按实际播放确认范围整理。
- Relay 验证短期票据并从服务端取上下文，不能信任浏览器提交的权限、Prompt 或面试状态。
- 数据库约束负责防重复会话、资格重复消费、旧结果覆盖和跨组织越权；Worker 处理结束、录音、摘要和评估。
- 单轮统一超时与重试预算、有限音频队列、资源释放和实时任务优先级。

## 2026-09-15 Prompt 模板

招聘工作台增加「Prompt 模板」页，按固定问题、主题引导、开放访谈三类组织 5 份完整文本。主题引导包含后端开发、软件测试场景推演和通用岗位简短初筛，具体问题与讨论顺序结合回答决定。按最新反馈删除独立面试计划、题数和时长展示；模板只有完整 Prompt 这一份行为配置，页面显示、复制和岗位应用直接使用同一文本。岗位编辑可原地选用、确认替换、自由改写并试聊，已有岗位与已发布版本不会被模板更新回写。验证结果见 [模板验证记录](prompt-templates-verification.md)。
