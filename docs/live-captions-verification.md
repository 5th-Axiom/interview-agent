# 双向实时字幕验证

日期：2026-09-15。

## 可运行行为

- 试聊和正式面试共用双向字幕，默认隐藏；开启后在圆球下方按发言顺序显示「AI 面试官 / 我」。
- 候选人的临时识别标记「正在转写」，修订更新同一行，最终识别去掉临时标记；AI 句子在播放开始时加入，多段音频不重复添加同一句。
- 已展示的被打断回复保留文字并标记最后一句；暂停和断线保留字幕，未完成识别标记「转写待确认」。停止的音频不能通过迟到的播放定时器追加字幕。
- 字幕区固定高度、内部滚动。上翻停止跟随，点击「回到最新」恢复；窗口尺寸变化不会被当成主动上翻。隐藏期间继续接收字幕，再次开启可见。
- 实时窗口保留本页最近 200 个片段，刷新后重新积累；完整记录仍通过既有保存流程保留，试聊结束后立即展示已保存对话。

## 验证结果

- `npm test`：79 项通过。覆盖字幕原地修订、旧修订丢弃、播放分块去重、打断标记、暂停状态、窗口上限、供应商连接轮换，以及 Relay 实时推送和旧客户端兼容。
- `npm run typecheck`、`npm run build`、`git diff --check` 通过。
- 浏览器检查 PC 1280 × 720 和 H5 390 × 844，覆盖浅色和深色。字幕独立滚动、身份与状态可辨，无横向溢出；通话按钮保持可达。
- 使用实际字幕组件和状态处理验证临时识别、最终修订、打断、上翻后收到新内容时保留阅读位置、回到最新及隐藏后重开。
- 使用实际 `RolePreview`、`VoicePanel` 和 Relay 完成测试模式收发：两次候选人回答均显示，暂停继续保留已有字幕，隐藏期间的回答重新打开后可见，结束后立即进入包含双方对话的记录。
- 临时验证页面与接口已移除；验证用试聊已结束。本地 Web、Relay 和 Worker 继续运行。

## 联调范围

浏览器完整链路使用明确标识的测试输入和合成静音音频，临时 ASR 与连接轮换使用供应商协议测试替身。本次未完成真人麦克风 ASR/TTS 联调，不能将以上结果视为真实语音识别效果的验证。当前本地服务仍运行在供应商联调模式，可继续人工试聊。
