# 试聊结束后立即查看记录

日期：2026-09-15。

## 可运行行为

- 手动确认结束、Escape 结束试聊、服务端自动结束均在结束流程成功后切换到同一窗口中的对话记录。
- 立即读取已保存文字，不等待录音整理或后台补转写；补转写完成后自动更新。失败时保留已有对话和重试入口。
- 区分「我」和「AI 面试官」，保留换行、时间与播放状态；ASR 修订采用当前版本，原始事件仍在数据库保留。
- 当前岗位编辑页面可以重新打开最近一次试聊记录。重新试聊创建独立会话；刷新或离开编辑器后不保留最近记录入口。本次没有新增历史记录列表或音频播放器。
- 记录接口仅允许本组织招聘方读取试聊，不返回正式会话或音频存储位置。

## 验证

- `npm test`：67 项通过。新增测试覆盖结束后后台任务仍待执行时即可读取、ASR 修订排序、播放状态、迟到补转写、场次隔离、跨组织与候选人访问拒绝、超时结束。
- `npm run typecheck`、`npm run build` 和 `git diff --check` 通过。
- PC 1280 × 720、H5 390 × 844，检查浅色和深色；对话区域独立滚动，操作按钮可见，无横向溢出，结束后键盘焦点进入记录区域。
- 浏览器使用独立新建岗位草稿和标为「合成数据」的试聊，没有保存或发布岗位。手动确认结束后看到记录；返回编辑后重新查看同一内容；新一场未产生文字时出现空状态，没有混入上次内容。
- 模拟服务端完成且没有 Relay 结束消息，页面通过服务端快照自动显示记录；追加补转写并完成后台任务后，对话由 6 条自动更新为 7 条，无需刷新。
- 供应商联调环境继续运行。本次浏览器麦克风被系统拒绝，对话用隔离的合成事件验证；没有把这次结果当作真人 ASR/TTS 联调结果。

## 边界

“立即展示”指结束流程完成后立即请求并呈现已持久化的文字，不等待后台任务。网络故障、未确认保存的片段或尚未完成的语音转写仍按实际状态显示，不能承诺在这些情况下已有完整转写。
