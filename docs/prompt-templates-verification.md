# Prompt 模板验证 · 2026-09-15

## 当前功能与边界

按最新反馈，模板页和岗位内的模板选择器删除独立的结构化面试计划、阶段编号、题数与时长统计，直接展示完整 Prompt。模板类型只用于目录筛选；展示、复制和岗位预填读取同一个 `prompt` 字符串，不维护或生成第二套阶段配置。

内置三类、5 份典型文本：

| 类型 | 示例岗位 | Prompt 中的行为 |
| --- | --- | --- |
| 固定问题 | 前端开发 | 明确题单和顺序，有限追问，已回答的内容避免重复 |
| 主题引导 | 后端开发 | 明确考察主题，根据回答调整讨论顺序，已覆盖主题不再重复 |
| 开放访谈 | 前端项目 | 不预设阶段或题单，从候选人经历中选择缺口追问，信息足够即收束 |
| 主题引导 | 软件测试 · 场景推演 | 在明确标识的假设案例中逐步讨论，保留已确认条件 |
| 主题引导 | 通用岗位 · 简短初筛 | 只收集相关经历、本人贡献和职责期望，覆盖后邀请提问并结束 |

各模板遵循单一连续上下文、恢复后接续、服务端岗位与时间事实、单轮单问、自然结束与主动结束的工具边界。没有要求新增题号游标、阶段状态、代码编辑器或白板。已有模板 ID 保留；更新模板不会回写已创建岗位或已冻结会话。

## 真实模型抽查

使用当前平台规则、各模板全文和服务端事实格式，向实际供应商发送合成对话。未使用真实候选人资料，也未将合成内容写入正式面试记录。

初版首轮与后续抽查：固定题目在背景回答后进入既定基础题；原后端分段模板围绕订单幂等继续追问；开放访谈承接复杂表单经历；场景推演明确假设案例并围绕已提出的条件交流。

简短初筛初次抽查出现额外偏好问题与重复贡献问题，已将题单改写成信息范围，补充“一次回答可覆盖多项”和“覆盖后直接邀请提问”的明确指令。最终复测在三项信息齐全后直接邀请候选人提问，对方没有问题后调用 `complete_interview`；结果记录在本地 `.local/template-types-model-result-general-screening.json`。

以上为短链路抽查，不能据此保证所有模型输出严格遵循 Prompt；本次未进行真人麦克风 ASR/TTS 全链路复测。面试计划和追问仍由 Prompt 引导，工程继续负责鉴权、保存、时间限制和工具执行。
