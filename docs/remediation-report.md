## 实际改变

- 轮次只由开场、新输入/修订、显式恢复等有效触发产生；已完成回复不会因后续噪声取消，也不会在 5 秒后自动重问。HTTP 控制绑定版本与连接代次，结束、换岗、接管期间的旧异步结果被隔离。
- Worklet 增加连续声音活动检测和静音边界确认；ASR 使用统一静音目标，供应商 final/interim、轮换尾部结果和保存重试均保留输入身份。静音不采集候选人录音；用于供应商判停的合成静音不进入录音或转写覆盖。
- 控制、实时 ASR 与对象保存分开排队。助手 PCM 先在 PostgreSQL 事务内持久化，再发送浏览器；后台合并归档。每批最多 10 个有界 PCM 片段，不将其误称为固定 2 秒。已保存的用户音频不能被同编号的不同内容覆盖。播放进度与证据事件原子提交。
- 浏览器保存队列按时长限流，积压达到 8 秒暂停采音；重新连接前先补传。页面内部换岗不丢待确认内容，源连接的播放凭据可在新连接通过 HTTP 补传。未确认数据仍只保留于当前页面进程内存；关闭浏览器、系统崩溃不会获得本地磁盘恢复保证，离开前会提醒。
- 模型只把完整确认播放的句子视为候选人听过；修订替代原逻辑输入而不删除原始事件。平台 Prompt 增加承认纠正、回应澄清、避免同角度循环、自然结束的规则。可朗读输出和工具通道分离，异常内容最多修复一次；这不等于已通过真人语义质量验收。
- Token 预算包含平台规则、工具、输出预留和安全余量；采用保守估算，尚非特定模型精确 tokenizer。65% 提前安排摘要，最近至少 6 个逻辑输入保留原文投影；摘要和长回答缓存均有来源、版本与 CAS，原文不删。达到硬上限时暂停并给出恢复提示。
- 实时、摘要、评估可分别配置模型、预算和并发。当前继续使用已配置的 `deepseek-chat`，没有擅自切换候选模型。管理详情新增安全阶段时间线；输入进度按约 1 秒抽样，关键 ASR/模型/合成/播放阶段保留，遥测使用独立有界队列，不阻塞控制回执；保存中继续输入的人工内容不会被回调清空。
- 统一 HTTP 错误解析及跨手动重试的命令编号；收紧候选人 DTO、代理头信任、持久化限流、OTP 发送事务、环境文件权限与部署错误捕获。跳过反馈不再把放弃的反馈录音提供给招聘方。

## 迁移、启动与回滚

新增 `migrations/005_voice_runtime.sql`，向后兼容新增列、表和索引，不删除会话或原始事件。部署必须先执行迁移，再启用新 Worker 和 Relay/Web；不要在旧 Worker 仍运行时启用新语音写入。既有会话保留 legacy 配置，新会话冻结协议、平台 Prompt、实时模型预算及语音模型/声音配置。供应商动态别名解析和凭据轮换仍由供应商/部署控制。

在选定的本项目独立数据库、私有存储配置完成后：

```sh
npm run db:migrate
npm run db:seed
npm run dev:all
```

离线回归使用 `npm run dev:test`；`npm run test:providers` 会调用真实供应商。验收脚本支持 `TEST_BASE_URL`，Relay 脚本另支持 `TEST_RELAY_URL`；`NEXT_DIST_DIR` 可隔离 QA 构建缓存。不要并行运行多个浏览器验收修改同一测试岗位。

`VOICE_RUNTIME_V2=false` 使后续新会话使用兼容配置；也可单独关闭 `VOICE_AUDIO_PIPELINE`、`VOICE_CONVERSATION_VIEW`、`VOICE_CONTEXT_BUDGET`。已开始会话保持冻结值。可靠性修复不回退；尤其继续运行新版归档 Worker 和保留 outbox/对象偏移读取，不能直接换回不理解新存储格式的旧二进制。迁移无破坏性回退步骤；不删除待归档 PCM。

页面部署前需提示已打开旧网页刷新；新协议会话收到旧客户端时返回刷新提示。生产安全配置仍由启动校验强制执行。本轮已在本项目本地数据库应用 005 迁移，并重启本地 Web 3100 / Relay 3101 / Worker，保留真实供应商配置；独立 QA 临时 schema 与服务已清理。没有发布远端站点、切换远端模型或修改参考仓库。
