## 本轮修复

- 反馈的前后端统一为最多 500 个 Unicode 字符，超限保留输入；问题标签与 PRD 一致；空反馈不能提交；跳过会确认放弃并不保存原内容；支持取消录音、失败重试转写；重面申请原因恢复为选填。反馈提交幂等且不会被迟到的重复提交覆盖。
- 麦克风授权、试音、反馈录音和岗位选择的异步返回增加退出隔离；错误后进入可恢复状态；旧回复完成事件不再修改新回复状态。模糊选岗可播报澄清，保留短期选岗历史。
- 按用户授权仅复制 LLM / ASR / TTS 凭据及对应配置到 `.env.local`（权限 0600、Git 忽略）；没有复制参考项目数据库、Supabase、存储或账号权限。参考仓库保持只读。
- 新增 DashScope ASR 和 TokenDance TTS 适配，真实等待 ASR task-started；流式 PCM 按 500ms 发送，保留网络半采样点，播放队列施加背压。测试登录与语音模式独立，每场固定真实 / 测试模式。
- ASR 轮换排空旧连接，修訂一条合并发言中的片段时保留其他片段；噪音打断后没有有效文字时由服务端接续；错误、取消、有限重试和连接代次贯穿语音链路。鉴权错误不当作临时故障重复请求供应商。
- 文本、音频和播放回执支持去重 / 重试；结束后的 30 秒收尾窗口仅接受本人当前连接在结束前采集的数据。尾部待识别音频由独立后台任务补转写，不触发实时对答；空识别结果作为音频核对事件，不假装候选人发言。
- 评估等待 30 秒尾片接收窗口和补转写任务完成后执行，避免晚到音频遗漏；所有评估证据链接都能定位可见的原文或辅助播放记录。
- 播放证据按生成句子的 event_id 关联，不能因同一轮其他句子的回执而误标已播放。上下文聚合播放回执，原始流水不变；超长单次发言可生成带来源的临时摘要视图。
- 修复摘要任务过早空跑一次后不再调度的问题；作业增加租约 token，领取、续租、结果写回和重试均隔离过期执行者；重复崩溃同样受三次预算限制；到期扫描独立运行。
- 评估要求支持仅保存、取消修改、生成前确认和版本冲突校验。失败 / 生成中继续显示旧草稿，人工意见保留。岗位保存增加乐观版本校验。
- 新建岗位尚未保存时，试聊不会在正式岗位列表产生草稿；试聊使用本组织招聘入口，关闭后资源释放，失败提供恢复提示。
- 面试记录按 50 条分页；岗位筛选覆盖历史片段；日期按上海时区解释并校验；保留筛选条件与加载重试。

## 外部条件和未作出的承诺

- 没有找到可用的真实短信服务与模板配置；当前没有发送真实短信。短信 HTTP 网关已实现，正式接入需要 `SMS_URL` / `SMS_TOKEN` 及供应商签名和模板。
- 招聘方当前为单组织口令工作台，具备服务端组织权限与口令哈希；未接客户 SSO / OIDC 和成员目录。
- 本轮使用真实 Chrome、供应商网络与合成语音。没有冒用真人音频，没有完成 iOS Safari / Android 实机、扬声器回声、蓝牙、真实弱网及长时间多实例容量验收。
- 端到端单次通过不能证明 P95 首声 2 秒或停声 300ms。最新单次记录：LLM 完整短回复约 1.10 秒，TTS 首个可播放分片约 2.56 秒，TTS 总耗时约 3.93 秒，短音频 ASR 约 1.32 秒。当前样本没有达到端到端首声 2 秒目标；记录见 provider-check.json，不作为生产 SLA。
- 上下文有字符预算、带来源压缩、最近原文和超长单轮视图；仍未采用所选模型的精确 Token tokenizer，也未形成大量场次的长期事实漂移基准。
- 原始音频仍以 200ms 分片保存，便于验证可靠性；尚未据此宣称大规模存储吞吐或成本目标。实时 Relay 有连接数、速率和队列上限，后台有低并发租约作业；容量上限需要目标并发与部署地域后实测。
- 正式域名 / 证书发布、数据保留政策、自动删除、备份恢复演练和成本运营看板不在本地供应商联调的通过结论内。未对其他项目或现有记录执行清理。
